# CAGI5 Variant Effect Prediction - H5 Output Format

This document describes the structure of the HDF5 output file generated by the CAGI5 Variant Effect Prediction script.

## File Structure Overview

```
cagi5_vep_results.h5
├── metadata/                    # Dataset and processing metadata
├── input_data/                  # Original input sequences and metadata
├── noise_schedule/              # Diffusion noise schedule information
├── method_cosine_similarity/    # Cosine similarity prediction results
├── method_score_matrix/         # Score matrix prediction results
└── evaluation_results/          # Evaluation metrics and correlations
```

## Detailed Structure

### 1. `metadata/` Group
Contains information about the dataset and processing parameters.

```
metadata/
├── dataset_info             # String: "CAGI5 Variant Effect Prediction"
├── model_checkpoint         # String: Path to D3 model checkpoint used
├── config_used             # String: YAML configuration (serialized)
├── num_sequences           # Int: Total number of variant sequences processed
├── sequence_length         # Int: 230 (CAGI5 sequence length)
├── num_noise_steps         # Int: Number of diffusion noise steps
├── methods_used            # String array: ["cosine_similarity", "score_matrix"]
├── genes                   # String array: ["F9", "LDLR", "PKLR", "SORT1"]
├── cell_lines             # String array: ["HepG2", "K562"]
└── timestamp              # String: ISO timestamp of analysis
```

### 2. `input_data/` Group
Contains the original CAGI5 data used for prediction.

```
input_data/
├── ref_sequences           # Shape: (N, 230, 4) - Reference sequences (one-hot)
├── alt_sequences           # Shape: (N, 230, 4) - Alternative sequences (one-hot)
├── mutation_positions      # Shape: (N,) - Position of mutation in each sequence
├── ref_nucleotides        # Shape: (N,) - Reference nucleotide (0=A, 1=C, 2=G, 3=T)
├── alt_nucleotides        # Shape: (N,) - Alternative nucleotide (0=A, 1=C, 2=G, 3=T)
├── ground_truth_scores    # Shape: (N,) - True variant effect scores from CAGI5
├── genes                  # String array: (N,) - Gene names for each variant
├── cell_lines            # String array: (N,) - Cell line names for each variant
└── identifiers           # String array: (N,) - CAGI5 variant identifiers
```

### 3. `noise_schedule/` Group
Contains information about the diffusion noise schedule used.

```
noise_schedule/
├── sigma_values           # Shape: (num_steps,) - Noise levels for each step
├── sigma_indices         # Shape: (num_steps,) - Step indices (0, 1, 2, ...)
└── default_sigma_idx     # Int: Index of default sigma used (5th to last)
```

### 4. `method_cosine_similarity/` Group
Contains results from the cosine similarity prediction method.

```
method_cosine_similarity/
├── default_step/
│   ├── ref_representations    # Shape: (N, hidden_dim) - Ref sequence embeddings
│   ├── alt_representations    # Shape: (N, hidden_dim) - Alt sequence embeddings  
│   ├── cosine_scores         # Shape: (N,) - Cosine similarity VEP scores
│   └── noise_level          # Float: Sigma value used for this step
└── all_steps/               # Only present if --save_intermediates was used
    ├── step_0/
    │   ├── ref_representations  # Shape: (N, hidden_dim)
    │   ├── alt_representations  # Shape: (N, hidden_dim)
    │   ├── cosine_scores       # Shape: (N,)
    │   └── noise_level        # Float
    ├── step_1/ (same structure)
    └── ... (one group per noise step)
```

### 5. `method_score_matrix/` Group
Contains results from the score matrix prediction method.

```
method_score_matrix/
├── default_step/
│   ├── ref_score_matrices     # Shape: (N, 230, 4) - Score matrices for ref sequences
│   ├── alt_score_matrices     # Shape: (N, 230, 4) - Score matrices for alt sequences
│   ├── ref_mutation_scores    # Shape: (N,) - Ref nucleotide scores at mutation positions
│   ├── alt_mutation_scores    # Shape: (N,) - Alt nucleotide scores at mutation positions
│   ├── score_differences      # Shape: (N,) - VEP scores (alt - ref)
│   └── noise_level           # Float: Sigma value used
└── all_steps/               # Only present if --save_intermediates was used
    ├── step_0/
    │   ├── ref_score_matrices   # Shape: (N, 230, 4)
    │   ├── alt_score_matrices   # Shape: (N, 230, 4)
    │   ├── ref_mutation_scores  # Shape: (N,)
    │   ├── alt_mutation_scores  # Shape: (N,)
    │   ├── score_differences    # Shape: (N,)
    │   └── noise_level         # Float
    └── ... (one group per noise step)
```

### 6. `evaluation_results/` Group
Contains evaluation metrics comparing predictions to ground truth.

```
evaluation_results/
├── overall_metrics/
│   ├── cosine_method/
│   │   ├── pearson_r              # Float: Overall Pearson correlation
│   │   ├── p_value               # Float: Statistical significance
│   │   ├── k562_pearson_r        # Float: K562 (PKLR gene) correlation
│   │   └── hepg2_average_pearson_r # Float: HepG2 average correlation
│   └── score_matrix_method/ (same structure)
│
├── per_gene_results/
│   ├── cosine_method/
│   │   ├── gene_names            # String array: ["F9", "LDLR", "PKLR", "SORT1"]
│   │   ├── pearson_correlations  # Shape: (4,) - Per-gene Pearson r values
│   │   ├── p_values             # Shape: (4,) - Statistical significance
│   │   └── sample_counts        # Shape: (4,) - Number of variants per gene
│   └── score_matrix_method/ (same structure)
│
├── per_cell_line_results/
│   ├── cosine_method/
│   │   ├── cell_line_names       # String array: ["HepG2", "K562"]
│   │   ├── pearson_correlations  # Shape: (2,) - Per-cell-line Pearson r
│   │   ├── p_values             # Shape: (2,) - Statistical significance
│   │   └── sample_counts        # Shape: (2,) - Number of variants per cell line
│   └── score_matrix_method/ (same structure)
│
└── all_steps_metrics/           # Only present if --save_intermediates was used
    ├── cosine_method/
    │   ├── step_0/
    │   │   ├── noise_level      # Float: Sigma value for this step
    │   │   ├── overall/
    │   │   │   ├── pearson_r    # Float: Overall correlation
    │   │   │   └── p_value      # Float: P-value
    │   │   ├── per_gene/
    │   │   │   ├── gene_names            # String array
    │   │   │   ├── pearson_correlations  # Shape: (4,)
    │   │   │   ├── p_values             # Shape: (4,)
    │   │   │   └── sample_counts        # Shape: (4,)
    │   │   └── per_cell_line/
    │   │       ├── cell_line_names       # String array
    │   │       ├── pearson_correlations  # Shape: (2,)
    │   │       ├── p_values             # Shape: (2,)
    │   │       └── sample_counts        # Shape: (2,)
    │   └── step_1/, step_2/, ... (one group per noise step)
    └── score_matrix_method/ (same structure)
```

## Data Types and Encoding

- **Float datasets**: Stored as float32 for memory efficiency
- **String arrays**: UTF-8 encoded byte strings
- **Missing values**: NaN values in correlations are saved as -999.0
- **Compression**: HDF5 datasets use default compression for space efficiency

## Usage Examples

### Loading Results in Python

```python
import h5py
import numpy as np

# Load the results file
with h5py.File('cagi5_vep_results.h5', 'r') as f:
    # Get metadata
    num_sequences = f['metadata/num_sequences'][()]
    genes = [g.decode() for g in f['input_data/genes'][:]]
    
    # Get predictions
    cosine_scores = f['method_cosine_similarity/default_step/cosine_scores'][:]
    score_diffs = f['method_score_matrix/default_step/score_differences'][:]
    
    # Get evaluation results
    cosine_r = f['evaluation_results/overall_metrics/cosine_method/pearson_r'][()]
    score_matrix_r = f['evaluation_results/overall_metrics/score_matrix_method/pearson_r'][()]
    
    print(f"Cosine similarity Pearson r: {cosine_r:.4f}")
    print(f"Score matrix Pearson r: {score_matrix_r:.4f}")
```

### Analyzing Noise-Level Performance (if --save_intermediates was used)

```python
import matplotlib.pyplot as plt

with h5py.File('cagi5_vep_results.h5', 'r') as f:
    # Extract performance across noise levels
    noise_levels = []
    correlations = []
    
    steps_group = f['evaluation_results/all_steps_metrics/cosine_method']
    for step_name in sorted(steps_group.keys()):
        noise_level = steps_group[f'{step_name}/noise_level'][()]
        pearson_r = steps_group[f'{step_name}/overall/pearson_r'][()]
        
        noise_levels.append(noise_level)
        correlations.append(pearson_r)
    
    # Plot performance vs noise level
    plt.plot(noise_levels, correlations)
    plt.xlabel('Noise Level (σ)')
    plt.ylabel('Pearson Correlation')
    plt.title('VEP Performance vs Diffusion Noise Level')
    plt.show()
```

## Command Line Options Affecting Output

- `--method both`: Saves both cosine similarity and score matrix results
- `--save_intermediates`: Adds `all_steps/` groups with results for every noise step
- `--samples_per_gene N`: Filters input to N random samples per gene before processing
- `--steps N`: Controls number of noise steps (affects `noise_schedule/` and `all_steps/` size)

## File Size Considerations

- **Default mode**: ~10-50 MB depending on dataset size
- **With --save_intermediates**: Size scales linearly with number of noise steps (can be 100s of MB to GB)
- **Large datasets**: Memory usage scales with number of variants × sequence length × number of methods × number of steps

## Quality Control

The evaluation results provide multiple ways to assess prediction quality:
- **Overall correlations**: General method performance
- **Per-gene correlations**: Gene-specific performance differences  
- **Per-cell-line correlations**: Cell type-specific effects
- **CAGI5 metrics**: K562 direct correlation and HepG2 averaged correlation following CAGI5 evaluation format
